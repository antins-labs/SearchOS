# 评测对话查看器

用于检查 `eval_results` 中 orchestrator 和子 agent 的消息，并比较同一题的多个运行。页面无外部依赖，数据保留在本机。

## 启动

在仓库根目录运行：

```bash
python3 tools/eval_viewer/serve.py
```

打开 <http://127.0.0.1:8765>。可用 `--root /绝对路径/eval_results --port 8766` 指定目录和端口。服务仅监听 `127.0.0.1`，按需读取选中的日志。结束时按 Ctrl+C。

也可以直接打开 `index.html`，点击“打开评测目录”选择 `eval_results`。离线方式依赖浏览器支持文件夹选择。服务端额外支持安全解析旧日志中 Python 字典字符串；离线方式保留这种旧格式原文。

## 使用

1. 左侧通过“实验目录”筛选实验，再搜索并选择题目。支持路径链接参数，例如 `?experiment=ablation/with_tool_result_compression`。按 benchmark、题号和规范化后的题目正文分组，避免同号异题混在一起。
2. 顶部“全屏”请求浏览器全屏；若嵌入浏览器不支持，会提示复制地址到独立浏览器。“专注阅读”收起题目区和侧栏；“放大此列”临时只显示一个 case，可恢复对比。
3. 展开“选择对比 case”，勾选多个实验。默认选中两个有完整对话的运行。每列独立选择 agent 和视图。
3. “完整对话”展示消息、reasoning、系统提示、工具参数和返回结果。长消息默认折叠；展开后才格式化正文。支持基础 Markdown 标题、表格、链接和代码块，以及嵌套 JSON。
4. “全部 agent”将消息按时间排序；没有时间戳的系统提示放在最前。“调度与执行轨迹”展示 trajectory 原始事件，保留 step 与 orchestrator_tool 两类记录，不合并重复事件。
5. 展开消息，点击子 agent 按钮查看其对话。工具消息显示 call_id 及同一视图中的配对记录编号。
6. 用顶部搜索和角色筛选缩小当前视图，每页 50 条。“同步滚动”按滚动比例联动，便于粗略对照，不代表语义或时间对齐。
7. 切换“最终答案”或“评测详情”检查结果。顶部导出按钮下载选中 case 的完整对话 JSON；每列可下载当前视图记录。

Item F1、Row F1 按百分比显示；Score 保持原值，缺失指标显示 `—`。实验路径完整展示，用于区分原始运行、重跑和重导出副本。

## 验证

```bash
python3 -m unittest discover -s tools/eval_viewer -p 'test_*.py'
```

服务模式同时发现 `eval_result.json` 和已有 session 日志的 case；没有评分文件的 case 标记“未出评测结果”，该标记不判断进程是否仍在运行。离线目录导入目前仅索引已有 `eval_result.json` 的 case。缺失或损坏的日志会在对应列提示。消息搜索只作用于各列已加载视图；检查全部子 agent 时请选择“全部 agent”。
