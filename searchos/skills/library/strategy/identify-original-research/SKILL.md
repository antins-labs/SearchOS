# Skill: identify-original-research

## 1. 适用条件与所需输入

**适用场景**
- 用户请求指向某项具体技术、方法、实验或发现的“首次提出”“原始论文”或“奠基性工作”。
- 检索结果中混合了原始研究、综述、评论、新闻报道、数据库介绍及后续应用研究，需要准确筛选。

**必要输入**
- 目标实体：待查的技术、方法、模型或实验名称（如 "AlphaFold"）。
- 核心事件特征：需解决的问题或关键能力（如 "high accuracy protein structure prediction"）。
- 时间窗口：预期的发表年份或时间范围（如 "2021 年"）。
- 排除标准：明确需排除的文献类型（如 "exclude review, database paper"）。

**缺失处理**
- 若用户未提供具体年份，需在查询中加入“里程碑”“首次”等限定词，并在结果中优先寻找被高引或标注为 "original article" 的记录。
- 若技术名称存在歧义（如通用词），需结合领域限定词（如 "deep learning" "protein"）消歧。

## 2. 数据目标与来源路径

**数据目标**
将“找到原始研究”转化为以下可验证的数据项：
1. **书目身份**：文章类型必须为 "Original Article" / "Research Article" / "Primary Research"，非 Review / Comment / Perspective / Database Resource。
2. **元数据**：完整题名、第一作者、期刊名称、DOI、正式发表日期。
3. **内容证据**：摘要原文或全文，用于概括主要结果。

**来源优先级**
1. **官方期刊/出版社站点**（如 nature.com, science.org, cell.com）：提供最权威的元数据、文章类型标签、DOI 和正式发表日期。优先验证。
2. **预印本平台**（如 arXiv, bioRxiv）：若原始研究先以预印本发布，需同时记录预印本发布日期与正式期刊发表日期，明确“首次公开”与“正式发表”的区别。
3. **学术索引数据库**（如 PubMed, Google Scholar, Web of Science）：用于初步筛选候选列表，获取引用关系与部分元数据，但必须回溯到出版社原文核验。
4. **机构/作者主页**：作为补充来源，核对作者列表与项目背景。

**路径判断**
- 若目标为生物医学领域，优先通过 PubMed 或出版社站点检索。
- 若目标为计算机/物理领域，优先检查 arXiv 等预印本与会议/期刊官网。
- 当出版社站点无法访问时，依赖于权威索引数据库的记录，但需在结果中标注“未直接核验原文”。

## 3. 查询构造与迭代

**查询模板**
```
[核心技术名] [核心能力描述] [年份限定] site:[期刊/学术域名]
```
或通用学术查询：
```
[核心技术名] [核心能力描述] original article [年份]
```

**变量说明**
- `[核心技术名]`：如 "AlphaFold"。
- `[核心能力描述]`：如 "protein structure prediction" "high accuracy"。
- `[年份限定]`：如 "2021"。
- `site:`：限制在特定期刊域名（如 `nature.com`）或学术平台（如 `scholar.google.com`）。

**迭代策略**
1. **初始查询**：使用技术名 + 核心功能 + 年份，不加过多限定，观察结果分布。
   - 例：`AlphaFold protein structure prediction 2021`
   - 观察：结果是否包含 Nature、Science 等期刊链接？是否有 "Highly accurate" 等题名关键词？

2. **缩窄查询**：若结果混杂评论或综述，加入文章类型排除词。
   - 例：`AlphaFold "Highly accurate" protein structure prediction 2021 -review -comment -database`
   - 或利用出版社的高级筛选功能，勾选 "Article" 排除 "Review"。

3. **扩展/替换查询**：若初始无结果，尝试：
   - 替换技术名别称或项目代号（如 "AlphaFold2"）。
   - 去掉年份限制，先找到相关文献，再根据元数据判断首发时间。
   - 搜索作者姓名 + 项目名，定位项目主页或预印本。

4. **切换来源**：若通用搜索引擎结果均为二手报道（新闻、博客），转向：
   - 学术索引数据库（PubMed, Google Scholar）。
   - 直接访问已知顶级期刊官网进行站内搜索。

**避免重复**
- 若已确认某链接为评论文章，后续查询应明确排除该 URL 或标题关键词。
- 记录已检查的候选文献，避免对同一链接重复发起请求。

## 4. 定位与提取

**从搜索结果到原文**
1. 点击进入出版社官方页面（优先级最高）。
2. 若无法直接访问，查找预印本链接或开放获取版本。

**页面内定位**
1. **文章类型**：检查页面顶部或底部的标签，如 "Article"、"Research"、"Review"、"Perspective"、"Comment"。必须确认为 "Article" 或 "Research Article"。
2. **题名**：提取页面 `<h1>` 或主标题区域的完整标题。
3. **作者**：定位作者列表，提取**第一作者**姓名。
4. **期刊与日期**：
   - 期刊名称通常位于页眉或引文信息区。
   - 查找 "Published"、"Published online"、"Issue date" 等字段，区分在线发表日期与期刊卷期日期。优先记录 "Published online" 日期作为首次正式发表时间。
5. **DOI**：通常在引文导出区域或页面底部，格式为 `10.xxxx/xxxxx`。
6. **摘要**：
   - 定位 "Abstract" 章节。
   - 提取完整摘要文本，用于后续概括主要结果。
   - 若页面仅显示部分摘要，尝试寻找 "Show more" 或 PDF 链接。

**证据记录**
- 记录来源 URL（出版社原文链接）。
- 记录提取的原文片段（特别是文章类型标签、发表日期、摘要首尾句）。
- 若需概括结论，必须基于摘要原文，不得依赖搜索结果摘要。

## 5. 核验与失败分支

**核验清单**
1. **实体一致性**：题名中的技术名/方法名是否与目标完全一致？是否为同名但不同技术？
2. **文章类型**：是否明确标注为 "Article" 或 "Original Research"？若为 "Review"、"Perspective"、"Comment"、"Editorial"、"Database Article"，则排除。
3. **时间匹配**：发表日期是否在用户指定的时间范围内？是否早于其他引用该技术的文献？
4. **内容匹配**：摘要是否描述了该技术的提出与验证，而非仅介绍数据库或评论他人工作？

**失败分支处理**
- **搜索结果全为二手报道/新闻**：
  - 动作：切换至学术索引数据库或期刊官网站内搜索。
  - 查询：加入 "journal" 或 "DOI" 等学术特征词。
- **无法确认文章类型**：
  - 动作：阅读摘要内容，判断是否包含 "we present"、"we demonstrate"、"our method" 等原创性表述；若为 "we review"、"this perspective discusses"，则排除。
- **存在多篇候选**：
  - 动作：对比发表日期与内容。若一篇为预印本，一篇为正式期刊发表，确认两者是否为同一工作，分别记录日期。
  - 判断：通常以正式期刊发表版本为最终引用对象，特殊情况需注明预印本优先。
- **原文无法访问**：
  - 动作：记录可获取的元数据（如通过 Google Scholar 或 PubMed），并标注“未直接核验原文，元数据来源于 [数据库名]”。
  - 不得将搜索摘要作为最终证据。
- **只有摘要无全文**：
  - 动作：基于摘要概括主要结果，并注明“结论基于摘要，未核对全文”。

## 6. 完成与停止

**完成标准**
- 成功定位一篇文献，满足：
  1. 文章类型确认为原始研究。
  2. 获取完整题名、第一作者、期刊名、DOI、发表日期。
  3. 基于摘要概括主要结果，并附上出版社原文 URL。
- 若存在多篇原始研究（如连续研究），需根据用户需求确认是否全部列出或仅限最核心一篇。

**停止条件**
- 已在权威出版社站点找到符合所有条件的文献，且无歧义。
- 搜索预算耗尽（如已尝试 3 种查询策略、访问 5 个链接），仍未找到完全匹配的原始研究，此时：
  - 报告已找到的最接近候选（如预印本或综述）。
  - 明确列出缺失项（如“未找到正式期刊发表日期”）。
  - 说明可能原因（如技术未正式发表、名称有误、年份记忆偏差）。

## 7. 应用示例（演示）

**任务特征**
- 目标：找到 2021 年介绍 AlphaFold 高精度蛋白质结构预测的原始研究论文。
- 排除：评论文章、数据库介绍。

**查询与来源选择**
1. 构造查询：`AlphaFold "Highly accurate" protein structure prediction 2021 site:nature.com`。
2. 原因：Nature 是顶级期刊，常发布此类突破性研究；"Highly accurate" 是该工作的标志性描述。

**观察条件**
- 假设搜索结果首位为 Nature 官方页面，标题包含 "Highly accurate protein structure prediction using AlphaFold"。
- 点击进入页面。

**下一步**
1. 检查文章类型标签：若显示 "Article"，继续；若显示 "Review" 或 "Perspective"，排除。
2. 提取元数据：
   - 第一作者：从作者列表首位读取。
   - 日期：查找 "Published online" 日期。
   - DOI：从引文区复制。
3. 阅读摘要：确认内容为提出方法并进行验证，而非介绍 AlphaFold DB。
4. 记录结果：输出题名、作者、期刊、DOI、日期及摘要概括，附上 Nature 原文链接。

**若遇到干扰结果**
- 假设同时出现 "AlphaFold Protein Structure Database" 论文。
- 判断：标题含 "Database"，文章类型可能为 "Resource" 或 "Article" 但内容侧重数据库。
- 验证：阅读摘要，若主要描述数据库构建与访问，而非预测算法本身，则排除，继续寻找算法原始论文。
