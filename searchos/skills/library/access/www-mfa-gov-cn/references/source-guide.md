# 中国外交部签证协定查询技能

本技能用于从中国外交部官网 (www.mfa.gov.cn) 提取中外互免签证协定数据。

## 功能说明

### 1. get_visa_agreements - 获取完整签证协定表

获取最新的中外互免签证协定完整列表，包含所有国家的详细信息。

**返回数据结构：**
- `page_title`: 页面标题
- `update_date`: 数据更新日期
- `total_countries`: 国家总数
- `agreements`: 所有国家协定列表
  - 每个国家包含：序号、协议国名称、互免签证协定列表
  - 每条协定包含：证件类别、生效日期、备注
- `statistics`: 统计信息（各护照类型覆盖数量）

**使用示例：**
```json
{
  "function": "get_visa_agreements"
}
```

### 2. search_by_country - 按国家查询

查询特定国家的签证协定信息。

**参数：**
- `country`: 国家名称（中文），支持部分匹配

**使用示例：**
```json
{
  "function": "search_by_country",
  "country": "阿尔巴尼亚"
}
```

### 3. get_by_passport_type - 按护照类型查询

查询持有特定类型护照可免签入境的国家列表。

**参数：**
- `passport_type`: 护照类型
  - 普通护照 / 普通 / ordinary
  - 外交护照 / 外交 / diplomatic
  - 公务护照 / 公务 / official
  - 公务普通护照 / 公务普通

**使用示例：**
```json
{
  "function": "get_by_passport_type",
  "passport_type": "普通护照"
}
```

## 数据说明

### 表格结构

原始表格采用 rowspan 嵌套结构，一个国家可能有多条协定记录（不同护照类型、不同生效日期）。本技能已将数据规范化为结构化格式，便于查询和分析。

### 字段含义

| 字段 | 说明 |
|------|------|
| 序号 | 国家编号 |
| 协议国 | 与中国签订互免签证协定的国家名称 |
| 证件类别 | 适用免签的护照类型 |
| 生效日期 | 协定生效日期 |
| 备注 | 特殊说明（如*1、*2等标记） |

### 护照类型

- **外交护照**: 外交人员专用
- **公务护照**: 公务出行人员使用
- **公务普通护照**: 因公出国人员使用
- **普通护照**: 普通公民因私出国使用

## 数据来源

数据来源于中国外交部官网"中外互免签证协定一览表"页面，定期更新。

## 注意事项

1. 签证政策可能随时变化，建议出行前再次确认最新政策
2. 部分协定可能有特殊限制条件（如停留天数、入境目的等），详见备注字段
3. 本技能仅提供协定信息，实际入境要求请以目的地国家官方规定为准
