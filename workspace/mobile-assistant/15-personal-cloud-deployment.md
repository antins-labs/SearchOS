# v0.8 个人云部署

目标：个人照文档在自己的 Linux 服务器部署 SearchOS，并通过 iPhone 发任务、收通知、查看报告。

## 本次取舍

- 一台主机、一个工作区、一个 API worker；采用 Compose + Caddy + Web + API。
- 先交付源码构建包，不引用尚未发布的“官方镜像”；容器 CI 独立验证。
- 复用管理员凭据和设备配对，不新增公开注册或宣称多租户隔离。
- 复用已有设置页的快速配置、模型与搜索配置。手机登录页给出凭据获取及配置入口。
- 标准指南明确为公网 HTTPS 登录方案，私网是另一种入口配置，不混淆两者。
- 数据和技能使用独立卷，支持停机一致备份与空卷恢复，拒绝覆盖和不安全归档。
- 主机卡区分 Mac 与服务器托管；不再给云端用户展示合盖、防休眠等提示。

## 验收边界

本地自动化验证归档恢复、启动失败关闭、配置持久化及现有配对/计划契约。
Linux 容器 CI 负责镜像构建、Caddy、真实 HTTP 链路、服务重启和数据卷恢复。
云服务器 DNS/证书、真实 iPhone 推送和真实模型研究需要在部署环境验收。
自动重启不等于研究续跑；备份恢复不等于无停机升级；快照中的活跃计划会随恢复启动。

面向用户的唯一部署步骤维护在 [个人部署指南](../../docs/zh/self-hosting.md)，避免多个文档中的命令漂移。

## 本地验证记录（2026-10-20）

- 后端相关测试 73 项通过：部署初始化/归档恢复、手机鉴权与计划、本机托管、设置 API。
- 前端 108 项测试、TypeScript、变更范围 ESLint 和独立生产构建通过。
- Shell 语法及 Git diff 空白检查通过。
- 修正设置测试的生命周期隔离，不再启动真实工作区的调度和恢复任务。
- 补充容器浏览器安装路径适配后，部署与技能命令测试共 42 项通过（与上述部署测试有重合）。
- 增加 `doctor` 检查浏览器和技能沙箱。宿主机限制导致技能隔离不可用时明确返回受限状态，
  不授予额外宿主权限；无桌面的服务器不支持依赖本机弹窗的认证流程。
- 当前开发机没有 Docker Engine/CLI；没有实际运行镜像构建、Compose、Caddy 或上述容器 CI。
  容器、真实云服务器和 iPhone 验收仍待执行，不能将这些本地检查视为云端上线完成。
