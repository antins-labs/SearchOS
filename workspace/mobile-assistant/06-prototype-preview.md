## 启动与预览

在 `web/frontend` 下运行：

```bash
npm run dev -- --hostname 127.0.0.1 --port 3100
```

打开 [移动端原型](http://127.0.0.1:3100/m)。仅监听本机回环地址，不开放局域网或公网；当前不能直接从另一台 iPhone 访问。可在电脑浏览器以手机宽度评审。桌面宽屏额外显示品牌介绍，手机宽度展示单栏页面。

## 可点击页面

| 入口 | 内容 |
| --- | --- |
| `/m` | 助理首页、输入框、建议问题、晨间简报、最近对话 |
| `/m/conversations/research` | 搜索对话、追加要求、停止、模拟完成 |
| `/m/runs/research` | 执行详情与研究要求 |
| `/m/tasks` | 搜索任务与定时计划切换 |
| `/m/schedules/new` | 新建计划表单 |
| `/m/schedules/daily` | 计划详情、编辑、暂停/恢复、立即演示一次、删除 |
| `/m/inbox` | 报告列表、未读过滤、全部已读 |
| `/m/reports/morning` | 报告排版、参考入口、复制摘要、继续追问 |
| `/m/settings` | 个人空间、连接与通知入口 |
| `/m/settings/connection` | 在线/离线状态模拟及未来配对说明 |
| `/m/settings/notifications` | 演示开关、免打扰、摘要预览、模拟通知跳转 |

## 建议评审路线

1. 在助理首页输入问题并发送，在对话中追加要求，然后点击“模拟完成”。
2. 打开报告，检查阅读层次与追问入口；在收件箱查看未读数变化。
3. 新建一个每周计划，保存、编辑、暂停，再回任务列表确认。
4. 在连接设置关闭“模拟设备在线”，回首页输入问题，确认提交被禁用。
5. 在通知设置打开演示开关，预览通知并点入报告。

## 本轮边界

- 所有状态在内存中，仅跨页面导航保留；刷新后重置，不连接真实搜索、配对、调度与推送。
- 搜索结果正文为明确标识的排版示例，不随问题真实生成。
- 每日/每周计划先演示固定选项；一次性日期、预算、完整时区编辑、登录/首次配对流程后续补齐。
- 通知预览是应用内卡片，不请求系统通知权限；尚未配置 PWA manifest 或 Service Worker。
- 移动路由跳过桌面 SettingsProvider，避免原型依赖桌面设置接口；桌面路由继续使用原 provider。
- 继续追问保留报告标题作为演示上下文，尚未实现后端报告快照语义。
