## 交互与实现约束

- 首页不因存在历史会话而被永久替换为对话页；从底部「助理」可以回到首页。
- 首页新建使用 `onRerun` 的 fresh-run 分支，避免自动续接旧会话；报告追问使用原 `onSubmit`，运行中补充使用 `onSteer`。任务状态仍由原控制器管理。
- 任务链接 `/m?session=…`、计划列表 `/m?view=tasks&tab=plans`、我的 `/m?view=me`、报告快照 `/m?report=…` 保留。初始化先读链接，再同步当前页面 URL。
- 报告条目和字段来自真实 coverage schema，不固定新闻标题、条数或内容。条目缺失、待核实和冲突提示保留。
- 资料选择不自动扩大到整库。未选择可用资料时不能确认；上传或后台处理完成后，选择页定时刷新真实状态。
- 多层报告弹窗只由最上层处理 Escape/Tab，避免关闭条目时连带关闭整个报告。
- 样式限定在 `/m` 的模块和主题容器；桌面搜索页面仍使用原有布局。沿用系统字体、卡片、低饱和蓝和真实品牌素材。

## 本机验证

- 前端 TypeScript、变更文件 ESLint、生产构建通过。
- 108 项前端测试通过，含新增的两项报告/条目嵌套弹窗焦点回归测试；已有资料范围、报告字段、来源链接、推送、历史续接与重连测试通过。
- 浏览器已核对：真实历史报告的 16 条展开、末条详情、上一条、返回、完整报告；独立输入与资料页往返保留草稿；任务及计划页、计划编辑频率条件字段、通知配置、主机状态；320px 首页和设置无页面横向溢出；正式服务的报告链接刷新恢复、桌面首页正常。
- 服务更新前确认无运行中研究、无启用计划；经 `web/service.py stop` → `install` 重建并恢复常驻服务。正式入口为 [本机移动端](http://127.0.0.1:3100/m)。
- 本轮未发起新的付费模型搜索，未改动真实计划和通知偏好；这些服务操作复用现有接口。当前没有用户资料，文件选择的真实非空状态和上传链路仍需要随首份资料实测。
- 未进行 iPhone 实机键盘、安全区、系统推送及远程网络验收；本机宽度测试不等同于实机验证。

## 后续维护

1. 新的移动 UI 变化同时维护本文和 13；接口、调度或远程安全配置变化更新 09。
2. 生产 UI 与原型分开维护。修改 `/m` 不会自动修改 ZIP；分享设计时仍以原型版本说明为准。
3. 实际远程入口、HTTPS 与 iPhone Web Push 按 09 配置和验收；此次迁移没有新增公网暴露或端口转发。
