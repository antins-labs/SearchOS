# SearchOS Mobile 07 · 墨蓝简报

更新：2026-10-19。状态：高保真交互原型，待评审。本文件为最新视觉基准；覆盖 12 文档中的 v0.6.x 视觉规则，不替代 08–10 中的真实功能、接口与部署说明。

## 设计目标

用户确认蓝色系、低亮度、卡片与功能小框。新的反馈是整体呈现仍过于初始，且「点击后开始执行」等说明没有必要。本轮重新组织页面构图和组件层级，清理重复说明，不继续堆叠局部配色补丁。

视觉方向：墨蓝报告封面、雾蓝背景、白色操作卡片。内容密度根据使用场景分配：交办页集中输入，任务页便于扫描，报告页逐层阅读。保留仓库既有 SearchOS 标志。

用户提及的 [Figma](https://www.figma.com/)作为设计与原型工作方式参考。交付是可在本机浏览器操作的 HTML 高保真原型，没有创建 Figma 云端设计文件或发布站点。

## 视觉规范

| 元素 | 基准 | 用途 |
| --- | --- | --- |
| 墨蓝 | `#304E74` | 首页最新简报、报告封面 |
| 操作蓝 | `#3B5C83` | 发送、确认等主操作 |
| 雾蓝 | `#F0F4F9` | 页面背景 |
| 浅蓝 | `#E8EFF8` / `#F0F5FC` | 选中项、条目卡片、图标底框 |
| 纸白 | `#FFFFFF` | 输入、任务、资料与设置卡片 |
| 正文 | `#20364E` | 标题与主要内容 |
| 边框 | `#DFE7F0` | 低对比容器边界 |

- 手机基准 390×844；窄屏 320px。页面横向边距 22px，窄屏 17px；组件内部 13–22px，根据内容层级一致分配。
- 主标题 27–30px，报告封面标题 24px，卡片标题 14–16px，阅读正文 16px；次级元信息以 11–13px 为主。
- 大卡片圆角 20–22px，列表卡片 17–19px，功能小框 9–14px。阴影仅提供微弱层次，边框承担主要边界。
- 功能图标同一线宽，不使用星芒；仅用于导航、操作、文件类型和状态，不给每段文字配图标。
- 主操作、底部导航、筛选和列表至少 44px 点击范围。按下态只轻微位移；尊重减少动态效果偏好。
- 底部导航使用独立白色圆角容器，选中入口用浅蓝底表达，不增加额外说明文字。

## 页面构图

| 场景 | 本轮设计 |
| --- | --- |
| 助理 | 品牌与轻量主机状态 → 问题输入卡 → 两个快捷入口 → 墨蓝最新简报 → 紧凑进行中任务 |
| 新任务 | 一个主要输入卡；下方集中设置资料、范围、深度；底部仅保留主操作 |
| 资料选择 | 标题与已选数量；文档卡片展示文件类型、标题、体积/状态；勾选后同步浅蓝底与边框 |
| 任务 | 执行/计划分段；状态筛选；每张卡片上方状态和时间，下方标题，避免重复图标和提示 |
| 定时计划 | 计划图标与开关；名称和醒目时间；底部下一次执行与历史入口 |
| 执行进度 | 状态、任务内容、阶段时间线分层；底部补充与停止 |
| 报告 | 紧凑墨蓝封面；白色摘要总卡及浅蓝条目；全部条目、单条详情、完整报告三个阅读层次 |
| 完整报告 | 白底阅读；章节、正文与引用有不同层级；追问留在底部 |
| 消息 | 图标、时间、未读点、标题、结果摘要，点击进入对应任务或报告 |
| 我的/连接/通知 | 统一分组卡片与开关；连接异常、系统授权等必要事实仍明确展示 |

总览按日常主页面优先排列全部 14 个画板，每个画板都可交互；可跳入带页面导航的评审模式。

## 文案取舍

删除：点击后开始执行、写清关注点会得到更合适的报告、取消不会改变之前选择的范围、按需调整、点击查看全部条目，以及重复的原型说明和完成提示。

保留：任务状态、时间、数量、文件处理状态、来源信息、时区、断线与权限说明。按钮直接表达动作，例如「开始任务」「使用这 2 份资料」「查看其余 13 条」。

原型身份统一在画板外和底部标记为「原型 · 示例数据」，避免虚构内容被当成实际研究结果；产品区域不反复说明如何操作。
