# SearchOS 移动工作区设计

版本：v0.5 · 更新：2026-10-15（Asia/Shanghai）。交付分支：`mobile`（AntCode）；原开发分支：`codex/mobile-assistant-prototype`。

## 当前实施基准

**手机是指令与结果入口，保留后端能力，重新设计手机交互并允许精简。** 当前基准为 [08 手机指令与结果入口](08-mobile-command-center.md)，用户已确认。导航调整为助理、任务、我的，重点为助理输入区、任务列表和资料选择。

`/m` 为手机入口，`/` 保留桌面工作区。即时搜索与资料继续复用后端；定时计划、消息、报告快照、设备绑定和 Web Push 已实现可配置服务。当前仅本机验证，未配置或开放外网入口。功能、配置、调度语义和验收边界见 [09 实现与本机验证](09-implementation-and-local-validation.md)。

## 已确认方向

- iPhone、个人使用优先，后续考虑多人。
- 后端能力继续复用，手机页面按交办任务、管理进展和阅读结果取舍，不照搬桌面。
- 后续支持手机远程交办即时搜索、定时简报，系统通知点击打开报告。
- 搜索与研究由现有 SearchOS 执行；移动端负责适配交互，并增量补齐远程连接及通知。
- 公司环境的网络与访问约束需要在远程接入方案中落实。

## 后续环境验收

用户已选择先完成可配置实现与本机验证，并增加本地常驻部署。实际网络接入方式、HTTPS 入口和 iPhone 实机通知仍待配置与验收；当前不穿透、不开放公网。实现选择单用户 PWA + 同源 API，后续多人隔离不在此次范围。

## 维护规则

1. 修改产品范围或实现时同步 08、09 和本索引，避免把旧演示能力当作真实能力。
2. 严格区分用户已确认、设计建议、已实现和已验证；复用原组件不等于全部端到端操作都重新验证。
3. 初期页面 P 编号、流程 F 编号、验收 A 编号仅用于引用对应历史设计。
4. 不在设计目录保存真实密钥、推送凭据、内部报告或用户数据。
